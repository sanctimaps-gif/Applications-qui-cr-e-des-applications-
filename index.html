Cette page, et l'outil complet

      

        Vous êtes sur l'édition navigateur de Forge : un seul fichier HTML, aucune
        installation, aucun serveur. Elle construit des applications web autonomes qui tournent
        directement dans l'aperçu, en appelant le fournisseur d'IA dont vous fournissez la clé.
      

      

        L'édition complète s'installe sur votre machine et va bien plus loin : elle
        construit n'importe quelle pile (Node, Python, Go, Rust, .NET…), exécute réellement
        install, build et
        test, corrige ses propres erreurs, publie sur GitHub, et
        n'impose aucune limite de création. Elle fonctionne avec 22 fournisseurs, dont quatre
        entièrement locaux — donc hors ligne.
      

      
git clone https://github.com/sanctimaps-gif/Applications-qui-cr-e-des-applications-.git
cd Applications-qui-cr-e-des-applications-
npm install && npm run build
export OPENAI_API_KEY=sk-...     # ou toute autre clé — ou Ollama, 100 % hors ligne
node dist/cli.js serve           # ouvre http://127.0.0.1:7331
